# Internationalization

This base uses Flutter gen-l10n.

Supported starter locales:

- English: `assets/l10n/app_en.arb`
- Vietnamese: `assets/l10n/app_vi.arb`
- Japanese: `assets/l10n/app_ja.arb`

## Adding Text

1. Add the same key to every ARB file.
2. Run:

```bash
flutter gen-l10n
```

3. Use:

```dart
Text(context.l10n.someKey)
```

## Rules

- Do not hardcode user-facing UI strings in pages/widgets.
- If translation is unknown, use a temporary English fallback in all ARB files and note it.
- Keep key names descriptive and stable.
